= Introduction to automation orchestrator

== Introduction

=== What is automation orchestrator?

Automation orchestrator is an add-on to Red Hat Ansible Automation
Platform: a composable canvas for designing, deploying, and
governing complex IT operations workflows.

A workflow is a sequence of connected *steps*. A trigger starts it,
steps do the work, and logic steps decide which step comes next. These
building blocks let you extend your existing automation with
AI-powered task agents, approval gates, and conditional branching.
Every Ansible job template you've already created can become a
reusable workflow step immediately, without modification.

=== Why should you care?

You can build more sophisticated IT operations workflows without
rebuilding the automation you've already invested in. By connecting
existing Ansible job templates with AI-powered capabilities and
decision-making logic, you can coordinate complex operations,
incorporate human oversight, and adapt workflows to different
situations.

Here's how those pieces come together on the automation orchestrator
canvas.

*The trigger is part of the workflow.* Manual, webhook, and
Event-Driven Ansible triggers are steps you place on the canvas
itself. You can also add multiple triggers to the same workflow,
giving you different ways to kick off the same automation. The
triggers and the automation they start are part of a single artifact,
and they export to JSON together.

*Switch steps route on values.* A switch evaluates a value produced
earlier in the workflow and directs execution down the first path that
matches. This lets you define multiple possible paths within a single
workflow, with the next step determined by the results of previous
steps.

*Task agents handle input you could not predict.* An incident ticket,
a log excerpt or an alert description arrives as free text that no
rule written in advance could cover. A task agent reads it,
classifies it, and recommends what to run, giving you a path through
the workflow for input you could not plan for.

*AI provides recommendations, AAP remains your trusted execution
layer.* AI can recommend what action to take, while AAP handles the
execution. Human-in-the-loop approvals let you decide when a person
should review and approve an action before it runs.

=== What you will build

Over six modules, you'll connect automation orchestrator to the tools
you already use, build workflows from scratch, and see them execute
against real systems.

* Your own *integrations and credentials*, connecting automation
  orchestrator to Ansible Automation Platform and to an AI model
* A *message of the day workflow* on an empty canvas: a trigger, a
  task agent, and an AAP job template that writes a login banner onto
  a real RHEL host
* A *disk utilization workflow* that branches on how full a filesystem
  is and hands the fix to AAP
* A *ticket enrichment workflow* where a task agent reads a live
  incident ticket and routes it to auto-remediation, an approval gate,
  or back to a human
* A *CVE auto-remediation workflow* that automatically patches
  development hosts while requiring approval before patching
  production hosts

Every one of them ends in a live run you can watch step by step.

== Who will benefit

This is a hands-on introduction to automation orchestrator. You don't
need any prior experience with it, and you won't have to write a
single Ansible playbook to complete the modules.

You'll get the most out of this lab if you are:

* An automation engineer or platform team member interested in using
  automation orchestrator alongside your existing Ansible Automation
  Platform environment
* Working with alerts, tickets, or logs that require someone to
  interpret the information before deciding which automation to run
* Curious about how AI-powered task agents can recommend actions while
  keeping humans in the loop when approvals are needed
* Evaluating automation orchestrator and would rather build and run
  real workflows than watch a demo

If you're familiar with the basics of Ansible playbooks and AAP job
templates, you have everything you need to get started.
